# PROXY-WAY

أداة عربية تجريبية لإنشاء خادم بروكسي محلي مع دعم اختياري للتشفير، وعقد وسيطة، واكتشاف عقد، وتكامل اختياري مع Tor. الواجهة والشرح في هذا المستودع باللغة العربية.

> **تنبيه مهم:** هذه الأداة ليست شبكة Tor مستقلة ولا تضمن إخفاء الهوية. العناوين الافتراضية داخل الملف أمثلة غير موثوقة، وقد تفشل أو تكون غير صالحة. استخدمها فقط على جهازك أو في بيئة تملك صلاحية اختبارها، ولا تمرر بيانات حساسة عبر عقد غير موثوقة.

## نتيجة التحقق

تم التحقق من أن الملف يمر باختبار الصياغة (`py_compile`) وأن الوحدات المحلية الأساسية تعمل: التشفير وفك التشفير، تحميل العقد الافتراضية، تحليل بيانات العقد، إدارة الاتصالات، وتشغيل القائمة والخروج منها. لم يتم اعتبار الاتصال الخارجي أو Tor ناجحًا؛ بيئة الاختبار لا تحتوي على Tor، كما أن تشغيل الأداة الفعلي يعتمد على إعدادات الشبكة والعقد المتاحة.

## المتطلبات

- Python 3.10 أو أحدث.
- الحزمتان الإلزاميتان: `requests` و`cryptography`.
- الحزمتان الاختياريتان: `PySocks` و`stem` عند استخدام Tor.

## التثبيت والتشغيل

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python PROXY-WAY.py
```

بعد التشغيل تظهر قائمة عربية. الخيارات هي تشغيل خادم البروكسي، تشغيل عقدة، عرض العقد المكتشفة، اختبار الاتصال، عرض إحصائيات الذاكرة، تفعيل أو تعطيل Tor، ثم الخروج.

للاختبار المحلي الآمن:

```bash
python -m unittest discover -s tests -p 'test_*.py'
python -m py_compile PROXY-WAY.py
```

## ملاحظات تشغيلية

يبدأ البرنامج افتراضيًا باكتشاف عقد في خلفية التنفيذ، وقد يحاول الوصول إلى مصادر خارجية. لا تشغل الأداة على شبكة إنتاجية قبل مراجعة الكود وإزالة العقد الافتراضية أو استبدالها بعقد تملك صلاحية استخدامها. تشغيل Tor يتطلب خدمة Tor محلية على المنفذ `9050`، وقد يتطلب منفذ التحكم `9051`، إضافة إلى تثبيت `PySocks` و`stem`.

الخادم يستمع على جميع واجهات الشبكة عند تشغيله (`0.0.0.0`). لذلك يُفضّل تشغيله محليًا أو تقييد الوصول بجدار ناري قبل استخدامه. لا توجد مصادقة مستخدم مدمجة، ولا ينبغي كشف المنفذ للإنترنت.
